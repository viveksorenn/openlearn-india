# OpenLearn India

**Free learning practice, built in the open.**

OpenLearn India is an early-stage, community-oriented learning project. This first version is a lightweight browser-based demo with short multiple-choice practice in vocabulary, grammar, and general knowledge.

## Current features

- Vocabulary, grammar, and general knowledge quizzes
- Instant answer feedback and a session score
- Responsive layout for phones and desktops
- A small English/Hindi hero-section language toggle
- No account or backend required

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a modern browser.

No build tools or dependencies are required.

## Project status

This is an initial prototype. It currently uses a small set of sample questions and does not yet have user accounts, saved progress, a backend, or a contribution community. Please do not describe it as having users, downloads, or adoption until those are measured.
