# Contributing to OpenLearn India

Thank you for considering a contribution!

## Ways to help

- Report a bug or suggest an improvement through a GitHub Issue.
- Add or improve quiz questions, including clear explanations.
- Help translate the interface into Hindi.
- Improve mobile usability, accessibility, or documentation.

## Before submitting changes

1. Keep questions factually correct and suitable for a broad learner audience.
2. Use clear language and include an explanation for each answer.
3. Test the site by opening `index.html` in a browser.
4. Keep changes focused and describe what you changed.

## Pull requests

1. Fork the repository.
2. Create a branch for your change.
3. Make and test your changes.
4. Open a pull request with a short description and screenshots if the visual layout changed.

Please be respectful and constructive in discussions.
